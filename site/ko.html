타이핑하기 전에, 지금 어떤 언어인지.

KeyHue는 지금 선택된 입력 소스의 색으로 Mac 화면 가장자리를 칠합니다. 치기 전에 한 번 보면 됩니다.

macOS용 다운로드 최신 버전. macOS 13 이상.

무료 오픈소스. Apple silicon과 Intel 모두에서 네이티브로 동작합니다.
모든 버전과 릴리즈 노트

여기서 직접 써 보세요

아무 언어로나 입력해 보세요. KeyHue가 화면 가장자리를 칠하듯, 이 페이지 맨 아래 막대의 색이 바뀝니다. Caps Lock도 켜 보세요.

  • 한국어
  • 일본어

앱은 macOS에서 실제로 선택된 입력 소스를 읽습니다. 이 페이지는 입력된 글자로 짐작할 뿐입니다.

처음 여는 방법

KeyHue는 무료 개인 프로젝트라 유료 Apple Developer ID 서명이 없습니다. 그래서 처음 한 번은 macOS에서 직접 허용해야 합니다.

  1. 내려받아 압축 풀기

    KeyHue.app을 응용 프로그램 폴더로 옮깁니다.

  2. 실행 허용하기
    • macOS 15 Sequoia 이상: KeyHue를 한 번 연 뒤 시스템 설정 › 개인정보 보호 및 보안에서 그래도 열기를 누릅니다.
    • macOS 13–14: KeyHue.app을 Control-클릭하고 열기를 고른 뒤, 한 번 더 열기를 누릅니다.
  3. 설정 열기

    Dock의 KeyHue를 누르거나, 메뉴바의 카멜레온을 누르고 설정…을 골라 색과 자동 전환을 정하세요. 모든 옵션은 사용 설명서에 있습니다.

KeyHue는 입력한 내용을 기록하지 않습니다

업데이트 확인을 위해서만 GitHub에 접속합니다. 하루 한 번 자동 확인하며 설정에서 끌 수 있습니다. 입력 내용·앱 활동·로그를 보내지 않고 분석 도구도 없습니다. 선택 기능은 켤 때만 권한을 요청합니다.
