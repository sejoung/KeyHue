# 0032. HUD는 전환하는 순간 바로 나타난다 (페이드 인 없음)

- 상태: Accepted (ADR 0025의 나타나는 방식과 유지 시간을 대체)
- 날짜: 2026-09-29

## 맥락
ADR 0025에서 HUD는 0.15초에 걸쳐 부드럽게 나타나 0.3초 머문 뒤 0.05초 만에 사라지도록 했다. 이후 "HUD가 보이면서 전환에 딜레이가 있는 것 같다"는 보고가 있었다.
- 입력 소스 전환 자체는 약 25 ms에 반영된다(ADR 0023). 하지만 HUD가 완전히 보이기까지 150 ms가 더 걸리므로, 사용자는 색을 확인하려고 그만큼 기다리게 되고 전환이 늦다고 느낀다.
- 타이핑을 시작하면 HUD를 바로 숨기는 기능(ADR 0025)은 키 입력을 알아야 한다. 그래서 ESC 옵션(입력 모니터링)을 켰을 때만 동작하는데, 이 조건이 화면에 드러나 있지 않았다. ESC 옵션이 꺼져 있으면 HUD가 약 0.5초 동안 글자 위에 떠 있었다.

## 결정
- **페이드 인을 없앤다.** 전환 알림을 받는 즉시 완전히 불투명하게 표시한다. 사라지는 중에 다시 전환해도 곧바로 불투명하게 되돌린다.
- 유지 시간은 0.3초에서 **0.25초**로 줄이고, 사라지는 시간(0.05초)은 그대로 둔다. 보이는 시간은 합쳐서 약 0.3초다(이전에는 약 0.5초).
- 타이핑하면 바로 숨는 기능은 그대로 두되, ESC 옵션을 켜야 동작한다는 점을 설정 창의 표시 섹션 안내 문구에 적는다.
- 이 기능 때문에 입력 모니터링을 따로 요구하지는 않는다. 권한은 기능을 켤 때만 요청한다는 원칙(ADR 0008)을 지킨다.

## 결과
- 통합 테스트
  - 시간이 전혀 흐르지 않아도 표시 직후 완전히 보인다.
  - 사라지는 중에 다시 전환하면 바로 완전히 보인다.
  - 사라지는 시간은 0.06초 이하, 전체는 0.35초 이하다.
  - 기존의 연속 전환, 타이핑 시 숨김, 오래된 숨김 예약 무시 테스트도 새 타이밍으로 유지한다.
- 전환 직후 타이핑이 늦게 느껴지는 것은 KeyHue를 끈 상태에서도 재현되어, HUD와는 별개의 macOS 쪽 문제로 따로 다룬다.
