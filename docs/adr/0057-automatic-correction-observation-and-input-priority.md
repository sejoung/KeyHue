# 0057. 고침 결과는 자동 관찰하고 다음 입력이 대기 작업을 중단한다

상태: Accepted (전용 Cocoa 클라이언트 검증, 일반 앱·제품 옵션은 별도)  
날짜: 2026-10-03

## 배경

[ADR 0056](0056-isolated-correction-and-undo-probe.md)의 실제 교체·되돌리기는 테스트용 F13으로 새 상태를 확인했다. 일반 키만으로 완료를 확인하려면 늦게 적용되는 편집·모드 변경과 빠른 다음 입력을 처리해야 한다. 동기 IMK 조회 중에도 자연 입력 callback이 재진입할 수 있었다.

## 결정

- F13 처리와 테스트 이벤트를 제거한다. Space는 기본 경로에서 한 번 확정하고, 대기 작업이 있는 동안만 메인 큐에서 10ms 간격으로 세션·클라이언트·원문/결과·UTF-16 범위·빈 선택·조합 종료·실제 모드를 관찰한다. 입력 이벤트를 큐에 보관하거나 재전송하지 않는다. 전용 테스트 앱 ID와 `dkssud` 사례 제한은 유지한다.
- 교체 결과를 확인한 뒤 모드를 요청하고 모드 적용까지 확인한다. 변경 전 상태가 정확히 유지되면 다음 관찰로 넘기며 같은 효과를 반복 요청하지 않는다. 한 차례 관찰에서 효과가 진행될 때만 최대 네 단계를 확인한다.
- 관찰 기한은 150ms다. 지나면 거부된 교체를 종료하거나, 여전히 소유하는 중간 결과만 복구한다. 복구 확인에도 150ms를 부여하고 이후 관찰을 종료한다. 이는 재조회 작업의 기한이며 **응답하지 않는 동기 IMK RPC 자체의 시간 제한은 아니다**. 일반 앱 지원 전에는 RPC 지연·실패 계약과 성능 기준이 필요하다.
- 새 키·클릭이 오면 먼저 이전 관찰을 취소한다. 아직 교체하지 않은 후보는 폐기한다. 이미 텍스트와 모드가 모두 적용됐으면 결과를 유지하고, 확인 가능한 중간 편집이면 현재 확인된 모드에 맞게 자기 범위만 복구한다. 대기 중인 자기 모드 요청은 필요하면 반대 요청으로 대체한다. 키는 실제 모드를 다시 읽어 기본 입력 경로에서 한 번 처리한다. 임의 클라이언트에서 이미 보낸 요청의 취소나 전달 순서를 보장한다고 가정하지 않는다.
- 컨트롤러·클라이언트·전면 앱·선택 소스가 달라지면 관찰을 폐기한다. 입력 context 종료는 실행 중인 조회도 세대로 무효화한다. 외부 편집이나 커서 이동으로 소유권 확인이 실패하면 덮어쓰지 않는다.
- 조회와 편집은 기존처럼 메인 스레드에서 수행한다. 재진입한 키가 새 되돌리기를 시작할 수 있으므로, 조회 전후 및 효과 요청 직전에 세대를 확인한다. 오래된 관찰은 새 작업을 지우거나 뒤늦게 모드를 요청하지 않는다.
- 테스트 창의 초기화는 남은 조합을 정상 Space로 확정한 뒤 문서를 비운다. 진행 로그를 매 단계 저장하고 stdout/stderr도 보관한다. 별도 60초 watchdog이 멈춘 테스트 앱을 종료하며 shell runner는 원래 소스와 유틸리티 실행 상태를 복원한다.

## 검증과 한계

`.artifacts/input-method-e2e/20261003-134316/`에서 F13 없이 전체 acceptance가 통과했다. 기본 입력·이동·모드 왕복, 네 UTF-16 접두사의 자동 고침/되돌리기와 재고침 억제, 세 번의 대기 없는 다음 키, 즉시 Backspace, 되돌리기 중 다음 키, 커서 이동·외부 편집 취소, 실제 교체를 거부하는 클라이언트의 기한 종료와 후속 입력을 확인했다. 전후 입력 소스 설정과 선택도 보존했다.

순수 테스트는 효과 지연 때 중복 요청 방지, 기한 종료와 소유 범위 복구, 중단된 모드 요청 순서, 다른 클라이언트·외부 편집 보존, 조회/편집 중 재진입으로 이전 작업이 새 되돌리기를 지우지 않는지 검사한다. 실제 필드/포커스 이동·외부 모드 왕복, 모드 거부 후 복구와 RPC 지연은 아직 앱별 검증이 필요하다. 현재 결과는 전용 클라이언트의 명시적인 사례에 한정하며 판정기·제품 설정·일반 앱 허용 정책을 연결하지 않는다.

후속 [ADR 0058](0058-external-mode-callbacks-and-native-editor-acceptance.md)에서 전용 클라이언트의 두 필드 이동·외부 ABC/한글 선택을 추가 검증하고, TIS 갱신보다 먼저 도착하는 외부 모드 요청에 대한 취소를 보완했다. 일반 앱 결과는 별도 호환성 표를 따른다.
