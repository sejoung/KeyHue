# 0034. macOS 입력 소스 표시(커서 옆 배지)를 숨기는 옵션을 둔다

- 상태: Accepted
- 날짜: 2026-09-30

## 맥락
"macOS가 한/영 전환 때 띄우는 표시를 끄니 전환이 훨씬 빠릿하다. 이걸 KeyHue에서 끄고 켤 수 있어야 하지 않나"라는 제안이 있었다.
- macOS 14부터 입력 소스를 바꾸면 커서 옆에 "한 / A" 배지가 뜬다. 기본으로 켜져 있고, 끄려면 숨은 설정(`defaults write -g TSMLanguageIndicatorEnabled -bool false`)을 알아야 한다.
- KeyHue는 이미 State Bar, 메뉴바 아이콘, HUD로 입력 상태를 보여 준다. 그래서 KeyHue 사용자에게 이 배지는 같은 정보를 한 번 더 띄우는 셈이다.

측정용 앱(텍스트 뷰 하나)으로 확인했다(macOS 26.6).
- **표시 여부**: 창 영역만 캡처해서 봤다. 켜져 있으면 ⌘Space로 바꿀 때나 TIS로 바꿀 때나 커서 옆에 파란 배지가 떴다.
- **적용 시점**: 앱이 실행 중일 때 값을 바꿔도 바로 적용됐다. 켜진 채 실행한 앱에서 끄면 배지가 사라졌고, 꺼진 채 실행한 앱에서 켜면 배지가 나타났다. 앱을 다시 실행할 필요가 없다.
  - 꺼도 작은 회색 배지는 남았다. 이 키가 막는 것은 전환할 때 크게 뜨는 파란 배지다.
- **입력 지연**: TIS로 전환하고 30 ms 뒤 키를 보냈을 때, 글자가 처리되기까지의 중앙값은 꺼짐 2.0 ms, 켜짐 3.7–7.1 ms였다(각 12회).
  - 몇 ms 차이라, 체감되는 느림의 주된 원인은 배지가 커서를 가리며 나타나는 모습으로 보인다.
  - 합성 ⌘Space로도 재 보려 했지만, 꺼진 상태에서 전환이 일어나지 않는 등 실제 키 입력과 다르게 동작해서 결과로 쓰지 않았다.
  - 무거운 앱(Electron 등)에서는 재지 않았다.

## 결정
- 설정 창 **일반 › 표시**에 **"macOS 입력 소스 표시 숨기기"**를 둔다.
- **KeyHue 설정에 저장하지 않고 macOS 설정의 실제 값을 읽고 쓴다**(`SystemInputIndicator`). "로그인 시 실행"과 같은 방식이다.
  - 전역 도메인(`kCFPreferencesAnyApplication`, 현재 사용자)의 `TSMLanguageIndicatorEnabled`를 쓴다.
  - 숨기면 false를 쓴다.
  - 다시 표시하면 true를 쓰지 않고 키를 지워 macOS 기본값으로 돌린다.
  - 터미널 등 KeyHue 밖에서 바꾼 값도 설정 창을 열 때 다시 읽는다. `defaults`로 쓴 정수 0도 숨김으로 읽는다.
- **KeyHue는 이 값을 스스로 바꾸지 않는다.** 설치나 첫 실행 때 끄지 않고, 사용자가 옵션을 켤 때만 바꾼다.
  - 모든 앱에 적용되는 macOS 설정이기 때문이다. 기능과 권한은 사용자가 켤 때만 쓴다는 원칙(ADR 0008)과도 맞다.
- 안내 문구에 "모든 앱에 바로 적용되는 macOS 설정이며, KeyHue를 삭제해도 유지된다"를 적는다. KeyHue를 지우기 전에 되돌릴 수 있도록 설명서에도 적는다.
- 메뉴바 메뉴에는 넣지 않는다. 자주 바꾸는 설정이 아니다.

## 결과
- 통합 테스트
  - 실제 전역 설정 대신 임시 폴더 경로를 도메인으로 쓴다. ~/Library/Preferences에 파일을 남기지 않고, 끝나면 지운다.
  - 기본은 표시한다.
  - 숨기면 false를 쓰고, 다시 표시하면 키를 지운다.
  - `defaults`로 쓴 정수와 불리언을 모두 읽는다.
  - 설정 창 토글은 actions를 거치고 KeyHue 설정을 바꾸지 않는다. 밖에서 바꾼 값은 창을 다시 열 때 반영된다.
- 로컬 점검: `Tests/perf/input-indicator.sh`
  - 측정용 앱을 띄운 채 설정을 표시 → 숨김으로 바꾸며 그 창만 캡처한다. 원래 설정으로 되돌린다.
  - 첫 실행: 표시 2장 모두 배지 있음(1,792·1,891픽셀), 숨김 2장 모두 없음(0픽셀).
  - 캡처는 `.artifacts/perf/input-indicator/`에 남는다(ADR 0035).
- 설정 창 높이를 680에서 780으로 늘리고 스크린샷을 갱신했다.
- 한계
  - Apple이 문서화하지 않은 키다. 이후 macOS에서 이름이나 동작이 바뀌면 옵션이 아무 효과가 없을 수 있다.
  - 표시를 숨긴 상태로 KeyHue를 지우면 배지는 계속 숨겨진다. 되돌리려면 지우기 전에 옵션을 끄거나 `defaults delete -g TSMLanguageIndicatorEnabled`를 실행한다.
