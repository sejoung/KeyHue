# 0039. 입력 소스가 사라지면 사용 가능한 대상으로 대체하고, 지원하지 않는 표시 언어는 영어로 보여 준다

- 상태: Accepted (0016의 시스템 언어 선택과 0029의 복원 대체 규칙을 보완)
- 날짜: 2026-10-01

## 맥락
입력 소스를 삭제하거나 끄면 저장한 기본 입력 소스와 앱·창의 기억이 더 이상 유효하지 않을 수 있다. 기존에는 삭제된 입력 소스 복원에 실패하고, 대상이 없는 설정 화면에도 ABC가 표시됐다. 표시 언어는 번들의 시스템 언어 선택에 맡겼으므로 지원하지 않는 언어와 번역 폴더 누락의 대체 동작도 명시적으로 검증해야 한다.

## 결정
- 실행 직전에 사용 가능한 입력 소스를 확인한다. 앱 복원은 사용 가능한 앞 창 기록 → 앱 기록 → 공통 기본 입력 소스 순서다. 창 복원 대상이 사라졌으면 공통 기본 입력 소스를 사용한다.
- 기본 입력 소스가 사라졌으면 기존 자동 선택(ABC → U.S. → 다른 영문 배열)을 사용한다. 자동 선택에서 이미 사용 가능한 영문 배열이면 유지한다. 대체 대상이 없으면 전환하지 않는다.
- 재시도는 실제로 실행한 대체 동작을 대상으로 한다. 실패한 전환은 검증하지 않으며, 새 요청이 이전 요청의 검증을 취소한다.
- 설정과 메뉴에는 없는 ABC를 표시하지 않는다. 삭제된 선택은 사용 불가 항목으로 남기고 대체 동작을 안내한다. 입력기가 다시 켜지면 저장한 선택을 다시 사용한다.
- 표시 언어가 시스템 설정이면 선호 언어 순서에서 en/ko/ja를 찾는다. 지역 태그도 인식하며, 지원하는 언어가 없으면 영어다. 명시적으로 선택한 표시 언어는 시스템 언어보다 우선한다.
- 번역 폴더가 없으면 영어 번들로 대체하고, 영어 번들이나 번역 키도 없으면 영어 원문 키를 사용한다. macOS의 언어 설정은 변경하지 않는다.

## 검증
- 가짜 시간과 입력 소스 목록으로 삭제된 앱·창 기록, 삭제 시점, 대체 대상 부재, 대체 동작 재시도, 이전 검증 취소를 재현한다.
- 실제 번역 번들로 지원하지 않는 언어, 지역 태그, 언어 우선순위, 명시적 선택, 번역 폴더·키 누락을 확인한다.
- 설정 모델에서 입력 소스 삭제·재추가와 대상이 없는 안내를 확인한다.
