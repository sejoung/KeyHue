# 0050. IMK 키 처리 전에 실제 선택된 입력 모드를 동기화한다

- 상태: Accepted (구현·자동 검증, 재설치 후 실제 앱 재확인 필요)
- 날짜: 2026-10-02
- 관련: [0048](0048-current-syllable-composition-and-input-mode-icons.md), [0049](0049-opt-in-input-method-integration.md)

## 맥락

사용자가 한글 → 영문 → 한글 전환 뒤 메뉴에는 한글이 표시되지만 영문이 계속 입력된다고 보고했다. 기존 컨트롤러는 `activateServer`와 `setValue:forTag:client:`에서만 `ProbeSession.mode`를 갱신하고, 키 입력 때 그 상태를 그대로 사용했다.

사용자 환경의 입력 내용 없는 상태 로그에서 2026-10-02 14:05:24·14:05:25 등 유틸리티의 ABC 경유 연결과 TIS 선택 성공은 기록됐지만, 입력기 로그에는 대응하는 활성화/모드 콜백이 없었다. 읽기 전용 TIS 조회에서는 한글 모드가 활성·선택된 상태였다. 모든 키가 실제로 어느 컨트롤러에 전달됐는지는 기존 로그에 없으므로 이 증상 전체를 재현·완치했다고 단정하지 않는다. 다만 콜백 없이 선택이 바뀌면 내부 모드가 영문으로 남는 경로가 코드에 있다.

로컬 Apple SDK의 `IMKInputController.h`는 활성화·모드 값 설정·키 처리 콜백을 별도 메서드로 제공한다. 이 실험에서는 모든 같은 서버의 모드 전환에 활성화/값 설정이 반드시 다시 전달된다고 가정하지 않는다.

## 결정

- 입력기 컨트롤러는 **매 keyDown 처리 전에** `TISCopyCurrentKeyboardInputSource`에서 선택 모드를 읽고 순수 세션의 `synchronize(inputSourceID:)`로 갱신한다. 영문자뿐 아니라 Backspace·경계·단축키 처리보다 먼저 적용한다. 이벤트 기반 조회이며 타이머·전역 키 가로채기·키 재전송을 추가하지 않는다.
- 명시적인 spike Hangul/Latin 소스 ID만 받아들인다. 부모 소스가 반환되면 해당 서버의 알려진 input-mode ID로 보완한다. 다른 입력 소스의 ID를 오래된 모드 속성이나 언어 이름으로 해석하지 않는다. 현재 모드를 식별하지 못하면 남은 자기 조합을 확정하고 키를 클라이언트에 전달한다.
- 활성화/모드 값 콜백에서도 실제 선택된 모드를 사용한다. 같은 서버의 더 최신 선택과 충돌하는 늦은 값 콜백은 선택 결과를 덮어쓰지 않는다. 아직 선택이 공개되지 않았다면 입력 시점까지 동기화를 미룬다.
- `ProbeSession.select`는 같은 모드에서 아무 편집 액션도 만들지 않는다. 중복 활성화·모드 콜백이 조합 중인 한 글자를 임의로 확정하지 않게 한다.
- 실제 모드가 바뀌면 기존 모드의 pending text를 한 번 확정한 뒤 새 모드로 현재 키를 처리한다. 다른 세션·이미 확정한 입력·사용자의 텍스트를 다시 쓰지 않는다.
- 키 시점에 모드를 보정한 경우 이전/현재 모드만 상태 로그에 남긴다. 키·글자·단어·문서 내용은 남기지 않는다.

## 결과와 검증

세션은 콜백 누락 때에도 선택된 소스 ID로 첫 키의 언어를 결정할 수 있다. 유틸리티의 두 모드 연결 규칙과 별도 권한·키 취소 정책은 변경하지 않는다. OS 전환 알림보다 먼저 다른 입력 소스로 들어간 키를 사후 고치는 기능도 제공하지 않는다.

순수 회귀 테스트는 콜백 없는 영문→한글 첫 키(`dkssud` → `안녕`), 양방향 전환 시 pending text 단일 확정, 반복 같은 모드 콜백에서 음절 보존, Backspace 전 동기화, 알 수 없는 소스에서 세션 불변을 확인한다. 기존 조합·삭제·306개 결정적 표본도 함께 유지한다. 테스트가 실제 IMK 콜백 전달이나 앱별 호환성을 검증한 것으로 표시하지 않는다.

적용에는 **입력기 번들 재설치**가 필요하다. 유틸리티 메뉴의 ‘연동 끄고 ABC로 전환’ → 조합 종료·ABC 선택 확인 → 입력기 설치 스크립트 → 한글 재선택·연동 재개 순서로 확인한다. 같은 앱/필드에서 한글→영문→한글을 반복해 각 전환 뒤 첫 키, 조합 중 전환, Backspace·Space를 비교한다. 모드 보정 로그와 실제 입력을 함께 확인해 남는 문제를 분류한다.
