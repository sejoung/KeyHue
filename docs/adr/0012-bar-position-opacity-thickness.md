# 0012. State Bar 위치·불투명도·두께를 설정 가능하게 한다 (기본 위치는 하단 유지)

- 상태: Accepted (ADR 0006의 두께 범위를 갱신하고 위치 옵션을 추가)
- 날짜: 2026-09-29

## 맥락
실제로 써 보니 화면 하단 3px 라인은 잘 보이지 않았다.
- 타이핑할 때 시선은 텍스트 커서와 화면 위쪽(탭, 주소창, 메뉴바)에 있다. 화면 맨 아래는 주변 시야에서도 가장 멀다.
- 하단에는 Dock이 있어서 라인이 Dock 가장자리에 묻힌다.
- 비슷한 도구(ShowyEdge 등)는 상단 메뉴바에 라인을 두는 방식을 쓴다.

사용자 요청은 불투명도 조절, 더 두꺼운 막대, 위치 선택이었다. 처음에는 기본 위치를 상단으로 바꿨다. 실제로 써 보니 **눈에는 확 띄지만 메뉴바를 가리는 느낌**이 있었다. 그래서 기본은 하단으로 되돌리고 상단은 선택 사항으로 남겼다.

## 결정
- **위치**: `BarPosition` = `bottom`(기본) / `top` / `left` / `right`.
  - frame 계산은 `ScreenGeometry.stateBarFrame(screenFrame:thickness:position:)` 한 곳에서 한다(단위 테스트 대상).
  - 상단 막대는 `screen.frame`의 맨 위(메뉴바 윗부분)에 놓는다. 패널 레벨 `.statusBar`(25)가 메뉴바(`.mainMenu`, 24)보다 높아서 메뉴바 위에 그려진다. 마우스 이벤트는 계속 통과한다.
  - 세로 배치(left/right)에서는 두께 값을 폭으로 쓴다.
- **두께**: 허용 범위를 1–12px에서 **1–16px**로 넓힌다. 메뉴 선택지는 1/2/3/4/6/8/10/12/16px. 하단 막대가 잘 안 보이는 문제는 위치 대신 두께로 푸는 것을 권장한다.
- **불투명도**: `barOpacity`(0.2–1.0, 메뉴 선택지는 100/80/60/40%)를 둔다. 상태색마다 따로 두지 않고 **막대 전체에 하나**만 적용한다.
  - 실제 막대 색은 `KeyHueSettings.barColor(for:)` = 상태색 × opacity로 구한다.
  - HUD와 메뉴바 카멜레온(ADR 0011)은 원래 상태색을 그대로 쓴다. 이 둘은 짧게 보이거나 크기가 작아서 흐리게 할 이유가 없다.
  - Custom 색상 선택 창의 alpha 슬라이더는 계속 숨긴다. 투명도 조절 경로를 하나로 유지하기 위해서다.
- `barPosition` 키가 없는 설정은 기본값 `bottom`을 적용한다.

## 결과
- 기본 동작은 README 명세의 원래 설계(하단)와 같다. 더 잘 보이게 하려면 두께를 키우거나(6–8px) 상단으로 옮기면 된다.
- 상단을 선택할 때 알아 둘 점:
  - 노치가 있는 MacBook에서는 막대가 노치 부분에서 끊겨 보인다.
  - 두꺼운 막대(약 10px 이상)는 메뉴바 아이콘 윗부분을 덮는다. 클릭은 통과하지만 시각적으로 겹친다.
  - Full Screen 앱에서 메뉴바가 숨겨지면 앱 콘텐츠의 맨 윗줄(탭 바 등)을 덮는다.
- 실측: 상단과 하단 배치 모두 내장·외부 모니터의 해당 가장자리에 막대가 붙는 것을 확인했다.
- 알려진 한계: `SettingsStore`는 어떤 설정이든 바뀌면 모든 키를 저장한다. 그래서 설정을 한 번이라도 바꾼 사용자에게는 이후 기본값 변경이 적용되지 않는다. 이번 기본값 변경도 기존 설치본에는 반영되지 않았다.
