# 0011. 메뉴바 아이콘은 앱 아이콘의 카멜레온 실루엣을 상태색으로 칠한다

- 상태: Accepted
- 날짜: 2026-09-29

## 맥락
처음에는 메뉴바 아이콘으로 SF Symbol `keyboard`를 썼으나 다른 입력 관련 앱과 구분되지 않아 특색이 없었다. 앱 아이콘(`docs/icon.png`)의 카멜레온은 "색이 바뀐다"는 KeyHue의 핵심 개념과 잘 맞는다. 다만 원본은 3D 렌더링이라 18pt 메뉴바 크기로 그대로 줄이면 알아볼 수 없다.

## 결정
- **빌드 시** `scripts/make-menubar-icon.swift`가 `docs/icon.png`에서 카멜레온 실루엣을 추출한다(원본 이미지 하나만 관리, ADR 0002와 동일한 방식).
  1. 채도 > 0.45 이고 명도 > 0.45인 픽셀만 남긴다 → 남색 배경, 흰 키캡, 눈(무채색)이 빠진다.
  2. 가장 큰 덩어리(몸통)와 그 영역 안의 덩어리(손발)만 남긴다 → 테두리 광택, 하단 무지개 바를 버린다.
  3. closing(반지름 = 폭/400)으로 머리와 몸통 사이 음영 틈을 닫는다. 반지름을 더 키우면 꼬리의 말린 모양이 뭉개진다.
  4. 작은 구멍은 메우고, 눈이나 꼬리 말림처럼 큰 구멍은 남긴다.
  5. 20×18pt(1x/2x) alpha mask PNG로 저장하고 `Contents/Resources`에 넣는다.
- **런타임**에는 mask를 현재 상태색(한글 초록 / 영문 파랑 / Caps 빨강 / 알 수 없음 회색)으로 칠한다. 카멜레온이 입력 상태에 따라 색을 바꾸는 셈이다.
  - 상태나 색이 바뀔 때만 다시 그린다(`renderedIconKey`로 중복 렌더링 방지).
  - Colors ▸ "Tint Menu Bar Icon"을 끄면 시스템 template(흑백) 이미지로 표시한다. 기본값은 ON.
- 번들 없이 실행하면(`swift run`) 리소스가 없으므로 SF Symbol `keyboard`로 대체한다.

## 결과
- 메뉴바에서도 입력 상태를 색으로 확인할 수 있어 State Bar를 보조한다. 멀티 모니터에서 State Bar를 끈 사용자에게도 유용하다.
- 컬러 아이콘은 macOS 메뉴바 관례(흑백 template)와 다르다. 관례를 원하는 사용자를 위해 끌 수 있게 했다.
- 추출 threshold는 현재 아이콘 그림에 맞춘 값이다. `docs/icon.png`를 바꾸면 결과를 다시 확인해야 한다.
