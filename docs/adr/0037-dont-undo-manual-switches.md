# 0037. 자동 전환 뒤 지켜보는 시간을 0.1초로 줄이고, 키 입력이 있으면 멈춘다 (직접 바꾼 것은 되돌리지 않는다)

- 상태: Accepted (ADR 0031의 `verifyDelay` 0.25초를 대체)
- 날짜: 2026-09-30

## 맥락
UI·UX를 점검하다 발견했다. 자동 전환 뒤 KeyHue는 시스템이 덮어쓰는지 지켜보다가, 덮어써지면 다시 바꾼다(ADR 0031).
- 그런데 입력 소스 알림만으로는 **시스템의 덮어쓰기와 사용자의 직접 전환을 구분할 수 없다.**
- 지켜보는 시간이 0.25초여서, ⌘Tab으로 앱을 바꾸자마자 ⌘Space로 한/영을 바꾸면 KeyHue가 되돌렸다. 빠른 사용자에게는 "내가 바꿨는데 다시 돌아간다"는 버그처럼 보인다.

ADR 0031의 실측이 기준이 된다.
- 시스템의 덮어쓰기 알림은 앱 활성화 후 12–36 ms에 왔다.
- KeyHue는 활성화 40 ms 뒤에 전환한다. 활성화 후 20 ms 이상 기다려 바꾸면 덮어써진 경우가 0/88이었다.
- 따라서 KeyHue의 전환 뒤에 오는 덮어쓰기는 드물고, 오더라도 곧바로 온다. 0.25초는 필요 이상으로 길었다.

## 결정
- **지켜보는 시간(`verifyDelay`)을 0.25초에서 0.1초로 줄인다.**
  - 사람이 새 앱이 뜬 것을 보고 한/영을 누르기까지는 이보다 길다.
  - 알림으로 바로 다시 바꾸는 것과 끝의 마지막 확인은 그대로 둔다.
- **지켜보는 중에 키 입력이 있으면 지켜보기를 멈춘다.** 사용자가 움직이기 시작했으므로 이후 변경은 사용자의 선택으로 본다.
  - 키 입력은 ESC 옵션(입력 모니터링)이 켜져 있을 때만 알 수 있다. 이 목적만으로 권한을 요구하지 않는다(ADR 0008).
  - 어떤 키인지는 보지 않는다.
- 창 전환도 같은 지켜보기를 쓰므로 함께 적용된다.

## 결과
- 단위 테스트(가짜 시간)
  - 지켜보는 시간이 0.05–0.1초 안에 있다.
  - 자동 전환 0.15초 뒤 사용자가 직접 바꾸면 그대로 둔다.
  - 지켜보는 중 키 입력이 있으면, 그 뒤의 변경을 되돌리지 않는다.
  - 키 입력 없이 곧바로 되돌려진 것은 여전히 바로잡는다.
  - ADR 0031의 기존 테스트(알림으로 바로 재시도, 마지막 확인은 한 번만, 되돌려진 값은 기억하지 않음)는 그대로 통과한다.
- 로컬 점검: `Tests/perf/app-switch-latency.sh`로 깜빡임과 실패가 없는지 확인한다.
- 한계: 무거운 앱(Chrome·Electron)에서 시스템이 0.1초보다 늦게 덮어쓰는 경우는 재지 않았다. 그런 경우에는 한 번 덮어써진 채로 남을 수 있다. 로그(ADR 0036)의 `auto reset`과 `caps=… source=…` 순서로 확인할 수 있다.

## 보완 (2026-10-03): 앱 전환 대기 중의 수동 전환
- 문제: 앱 전환 후 결정을 미루는 40 ms 대기(ADR 0031) 동안 사용자가 ⌘Space 등으로 바꾸면, 대기가 끝난 뒤 자동 전환이 그 선택을 덮어썼다. 위 결정은 전환 **뒤**의 지켜보는 시간만 다뤘다.
- 대기 중의 변경은 macOS가 스스로 한 것(문서별 입력 소스)일 수도 있어 알림만으로는 구별되지 않는다. 그래서 대기 중에 **수정 키가 붙은 키나 마우스 클릭**이 있은 뒤의 변경만 사용자의 선택으로 본다. 그 앱의 자동 전환을 취소하고, 바뀐 Source를 새 앱 몫으로 기록한다. 로그에는 `kept manual switch made while the app switch settled`가 남는다.
- 글자 키는 근거로 보지 않는다. 앱을 바꾸자마자 치기 시작해도 자동 전환은 그대로 일어난다.
- 한계: Caps Lock 전환은 키 입력으로 보이지 않아 구별하지 못한다. 입력 모니터링 권한이 없거나 마우스를 보지 않는 설정이면 근거가 없어 이전과 같이 동작한다. 대기 중 다른 단축키(⌘C)와 macOS의 전환이 겹치면 사용자 선택으로 볼 수 있다.
- 테스트: `ManualSwitchDuringSettleTests`(단축키 뒤 변경 유지·기록, 복원 옵션, 입력 없는 변경은 macOS로 처리, 글자 키, 변경 없는 단축키, 다음 앱으로 넘어가지 않음, 대기 밖은 기존 규칙).
