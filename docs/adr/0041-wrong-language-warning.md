# 0041. 잘못된 언어 경고(실험적, 1a단계): 단어가 끝나면 바꾼 단어를 메시지로 보여 주고 막대를 깜빡인다

- 상태: Accepted (실험적 기능, 기본 꺼짐. 0040의 판정기를 앱에 연결한다. 판정 시점은 0042에서 치는 중으로 앞당겼다)
- 날짜: 2026-10-01

## 맥락
ADR 0040에서 판정기를 공개 말뭉치로 쟀다. 오탐은 1,000단어당 1회보다 훨씬 적었다. 다만 오타, 섞어 쓰기, 실제 입력 분포처럼 말뭉치로 잴 수 없는 것은 직접 써 봐야 한다.

자동으로 고쳐 쓰는 기능(지우고 다시 치기)과 자동 전환은 판정이 틀렸을 때 비용이 크다. 그래서 먼저 **알리기만** 한다. KeyHue의 역할("지금 어떤 언어로 입력될지 보여 준다")에도 맞다.

## 결정
- **옵션:** 자동 전환 탭 › 실험적 기능 › "다른 언어로 치고 있으면 알리기"(`warnOnWrongLanguage`).
  - 기본은 꺼짐이고, 켤 때 입력 모니터링 권한을 묻는다(ADR 0008, 0009와 같은 방식).
  - 두벌식과 QWERTY 영문 배열(ABC, U.S., British 등)이 둘 다 켜져 있을 때만 보인다. 켜 둔 뒤 입력 소스를 지웠으면 끌 수 있게 계속 보인다.
  - 메뉴에는 넣지 않는다(ADR 0038: 메뉴는 자주 쓰는 것만).
- **입력:** ESC와 같은 listen-only 이벤트 탭을 쓴다.
  - 키 코드와 수정 키만 읽고, 이벤트의 문자열은 읽지 않는다. 키 코드는 위치이므로 같은 표로 영문과 두벌식을 함께 푼다(`MistypeKeyMap`).
  - 이 옵션을 켰을 때만 마우스 클릭도 받는다. 커서가 움직였을 수 있음을 알기 위해서이며, 위치는 읽지 않는다.
- **단어 단위 판정**(`MistypeWordTracker`, Core): 스페이스·리턴·탭에서 판정한다. 오탐을 줄이려고 확실한 단어만 본다. 다음 경우에는 판정하지 않는다.
  - 지우기로 고친 단어. 말뭉치로 잴 수 없던 오타 오탐을 줄인다.
  - 문장 부호 뒤에 글자가 이어진 단어. 끝에 붙은 문장 부호는 괜찮다.
  - 숫자·화살표·단축키 뒤의 글자.
  - 단어 중간에 입력 모드가 바뀐 경우.
  - Caps Lock이 켜져 있거나 지원하지 않는 입력 소스인 경우.
  - 40타를 넘는 단어.
  - 마우스 클릭과 앱 전환은 모으던 단어를 버린다.
- **경고 표시:** 두 가지를 함께 한다.
  - **메시지**(`WrongLanguageToast`): 화면 아래 가운데에 의도한 언어 색의 카멜레온, 그 언어로 바꾼 단어("안녕?"), "두벌식(으)로 치려던 건가요?"를 1.6초 보여 준다.
    - 계속 타이핑해도 바로 숨지 않는다(전환 HUD와 다르다). 단어를 읽을 시간이 필요하기 때문이다.
    - 처음에는 막대만 깜빡였는데, 직접 써 보니 0.7초 깜빡임은 놓치기 쉬웠다(2026-10-01 피드백: "알림 메시지가 안 뜬다").
  - **막대 깜빡임:** 의도한 언어의 입력 소스 색으로 State Bar를 3번 깜빡인다(켜짐 0.14초, 꺼짐 0.09초). 깜빡이는 동안은 최소 6pt로 굵게 한다.
    - 끝나면 지금 상태의 색과 두께로 돌아온다. 깜빡이는 중 상태가 바뀌어도 마찬가지다.
    - 막대를 꺼 두었으면 메시지만 보인다.
  - 입력한 글자와 입력 소스는 바꾸지 않는다.
  - 타이밍은 `Scheduling`으로 주입해 가짜 시간으로 테스트한다(ADR 0026).
- **개인정보:** 모은 키는 메모리에만 두고 단어마다 지운다. 바꾼 단어는 경고 메시지로 화면에만 보인다. 로그에는 판정 방향(`meant hangul`/`meant latin`)만 남긴다. README·설명서의 개인정보 표에 적는다.
- **영어 사전:** NSSpellChecker(en)를 쓴다(`SystemEnglishLexicon`). 로마 숫자 글자로만 된 문자열은 `/usr/share/dict/words`에도 있어야 단어로 본다(ADR 0040). 측정 도구도 같은 파일을 쓴다.
- **음절 모델:** 한국어 위키백과로 학습해 앱 번들에 넣는다(`Resources/Mistype/hangul-syllables.tsv`, 1.8MB). 켤 때 한 번 백그라운드에서 읽는다.
  - 덤프 kowiki-20260901, pages-articles1(일반 문서 33,950개, 단어 1,440만 개).
  - `scripts/build-mistype-model.sh`로 다시 만든다. 위키 문법을 걷어 내고, 측정과 같은 단어 규칙을 쓴다.
  - 파일 형식은 정렬된 탭 구분 텍스트라 다시 만들면 같은 파일이 된다.
- **판정 임계값**(측정으로 정함)
  - 영문 모드 → 한글: 3타 이상, 점수 −2.75 이상.
  - 한글 모드 → 영어: 2타 이상, 점수 −2.5 미만이거나 낱자 모음이 남은 경우.

- **갱신(2026-10-01, 직접 써 본 뒤)**
  - **"메시지로 알리기" 하위 옵션**(`wrongLanguageShowsMessage`, 기본 켜짐)을 둔다. 끄면 막대 깜빡임만 한다.
    - HUD 설정에 묶지 않는다. HUD는 "입력 소스가 바뀌었다"는 확인용이라 귀찮아서 끄는 경우가 많다. 이 경고는 기능을 켠 것 자체가 알림을 받겠다는 뜻이다.
    - 실제로 HUD를 끈 상태에서 막대 깜빡임만으로는 경고를 놓쳤다("알림 메시지가 안 뜬다").
    - 메시지도 끄고 막대도 숨기면 경고가 보이지 않으므로, 설정 창에 그 사실을 알린다.
  - **한국어 입력 사용자용 기능임을 분명히 한다.** 다른 언어 사용자가 이상하게 여기지 않도록 다음과 같이 바꿨다.
    - 섹션 머리말: "실험적 기능 · 한국어 입력"(Experimental · Korean Input).
    - 이름: "한/영을 잘못 치고 있으면 알리기"(Warn When Korean and English Are Mixed Up).
    - 권한 안내와 설명도 "영문 모드로 친 한글"처럼 구체적으로 쓴다.
    - 두벌식과 QWERTY 영문 배열이 없으면 원래대로 보이지 않는다.

## 라이선스
- **0단계의 학습 말뭉치(Leipzig 한국어 뉴스)는 쓰지 않는다.**
  - Leipzig Corpora Collection의 이용 조건을 공식 페이지에서 확인할 수 없었다. 단어 목록은 CC BY라는 2차 정보만 있다.
  - 원문이 뉴스 기사여서 저작권이 불분명하다.
- **한국어 위키백과는 CC BY-SA 4.0이다.**
  - 모델 파일에는 음절 1개와 이웃한 음절 2개의 횟수만 들어 있고, 문장이나 단어는 들어 있지 않다.
  - 그래도 2차적 저작물로 볼 여지를 피하려고, 모델 파일만 CC BY-SA 4.0으로 배포한다. 출처, 덤프, 변경 내용은 `Resources/Mistype/LICENSE`에 적는다.
  - README의 라이선스 절에 "이 파일은 MIT가 아니다"라고 적는다. 코드는 계속 MIT다.
- Leipzig·Tatoeba 말뭉치는 측정에만 쓰고 저장소와 앱에 넣지 않는다(`.artifacts/corpora/`). Tatoeba는 CC BY 2.0 FR이다.
