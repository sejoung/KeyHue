# 0014. 설정은 기본값과 다른 값만 저장한다

- 상태: Accepted (ADR 0010의 저장 방식을 갱신)
- 날짜: 2026-09-29

## 맥락
기존 `SettingsStore.save()`는 설정이 하나라도 바뀌면 **모든 키를 현재 값으로** 저장했다. 그래서 사용자가 어떤 설정이든 한 번 바꾸면, 건드리지 않은 설정의 기본값까지 고정됐다. 실제로 State Bar 기본 위치를 상단에서 하단으로 되돌렸을 때(ADR 0012) 기존 설치본에는 `barPosition = top`이 이미 저장돼 있어 반영되지 않았고, 저장값을 직접 고쳐야 했다.

## 결정
- 저장할 때 값이 `KeyHueSettings()` 기본값과 같으면 **키를 지운다**. 다를 때만 저장한다.
- 앱 시작 시 한 번 같은 규칙으로 정리한다. 이전 버전이 저장해 둔 "기본값과 같은 값"과 레거시 키(`koreanColor`/`englishColor`)를 지운다.
- 사용자가 기본값과 같은 값을 직접 고르면 "기본값을 따름"과 같은 뜻으로 본다. 입력 소스 색도 기본색과 같은 색을 고르면 항목을 지운다(ADR 0013).

## 결과
- 이후 버전에서 기본값을 바꾸면, 사용자가 건드리지 않은 설정은 새 기본값을 따른다.
- 실측: 기존 설치본의 설정 15개 중 사용자가 실제로 바꾼 3개(두께 8px, ESC 전환, HUD)만 남았다.
- 트레이드오프: "지금의 기본값을 일부러 골랐으니 앞으로도 유지해 달라"는 의도는 표현할 수 없다. 이런 요구가 생기면 명시적 버전 마이그레이션으로 처리한다.
