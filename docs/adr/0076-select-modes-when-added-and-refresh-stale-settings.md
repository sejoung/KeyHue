# 0076. 두 모드가 나중에 추가되면 그때 선택하고, 설치 전에 열린 시스템 설정은 새로 연다

상태: Accepted (구현·자동 검증, 처음 설치 시나리오로 확인)

날짜: 2026-10-06

관련: [0055](0055-users-add-input-sources-manually.md), [0071](0071-route-through-the-leaving-mode-and-wait-for-modifier-release.md), [0074](0074-uninstall-script-resets-to-first-install.md), [0075](0075-check-accessibility-only-for-features-that-use-it.md)

## 배경

ADR 0074의 처음 설치 시나리오에서 사용자가 두 가지를 보고했다(2026-10-06 13:54~13:56, 빌드 101).

**1. KeyHue 한/영을 골라도 ⌘Space가 기존 두벌식·ABC로 오간다.**

- 켜진 입력 소스는 ABC, 시스템 두벌식, KeyHue 영문·한글이다.
- 두 모드를 추가한 뒤에도 ⌘Space(이전 입력 소스)는 13:55:33~55 동안 두벌식 ↔ ABC만 오갔다. KeyHue의 선택 기록은 없었다.
- "이전 입력 소스"는 최근에 쓴 두 소스를 오간다. 기록에는 사용자가 전에 쓰던 두벌식·ABC가 남아 있었다.
- ADR 0071은 설치 직후 두 모드가 이미 켜져 있을 때만 영문 → 한글을 선택한다. 이번처럼 설치 뒤 시스템 설정에서 모드를 추가하면 그 선택이 없다.

**2. 시스템 설정의 + 목록에 처음에는 KeyHue 모드가 보이지 않았다.**

- 영문·한국어 목록에 KeyHue 모드가 없었다. 추가 버튼을 그냥 누르자 추가됐고, 그 뒤로는 목록에 보였다.
- KeyHue는 13:54:23에 입력기를 등록했다. 설치 안내에서 연 시스템 설정은 13:35부터 떠 있던 프로세스였다. 그 프로세스는 등록 전의 입력 소스 목록을 그대로 쓴 것으로 보인다. 목록이 바뀌는 다른 일(추가)이 생기자 새로 읽었다.

## 결정

- **나중에 추가된 두 모드:** 켜진 입력 소스 목록이 바뀔 때, 두 KeyHue 모드가 처음으로 모두 켜지면 KeyHue 영문 → 한글을 선택한다. 조건은 연동과 두 모드 유지가 켜져 있는 것이다. ADR 0071의 설치 직후 선택(`selectKeyHueHangulAfterSetup`)과 같다. 이후 ⌘Space는 두 KeyHue 모드를 오간다. 실행할 때 이미 켜져 있으면 선택하지 않는다(전환이 아니라 기준값).
- **설치 전에 열린 시스템 설정:** "입력 소스 설정 열기"를 누를 때 실행 중인 시스템 설정이 입력기 설치보다 먼저 열린 것이면 끝내고 새로 연다.
  - 설치 시각은 `~/Library/Input Methods` 폴더의 수정 시각이다. 복사한 번들은 빌드 시각을 유지하므로 번들의 시각은 쓰지 않는다.
  - KeyHue에는 Apple Events 권한이 없어 일반 종료 요청을 보낼 수 없다. 그래서 강제 종료한다. 시스템 설정에는 저장하지 않은 문서가 없다.

## 결과

- 처음 설치의 순서(설치 → 시스템 설정에서 추가)와 상관없이 ⌘Space가 KeyHue 두 모드를 오간다. 사용자가 이후 메뉴에서 시스템 두벌식을 고르면 기록에 다시 들어간다. 그것은 사용자의 선택이다.
- 설치 안내에서 연 시스템 설정의 + 목록에 KeyHue 모드가 처음부터 보인다. 사용자가 직접 연 오래된 시스템 설정 창에는 적용되지 않는다.

## 검증과 한계

- `scripts/verify.sh` 통과. 두 동작은 앱 연결 코드라 단위 테스트가 없다.
- 처음 설치 시나리오(ADR 0074, `docs/TESTING.md`)로 다시 확인한다.
  - 시스템 설정을 미리 열어 둔 채 입력기를 설치하고, 안내에서 연 + 목록에 KeyHue 모드가 바로 보이는지
  - 두 모드를 추가하자마자 ⌘Space가 KeyHue 모드를 오가는지
- 시스템 설정의 목록 캐시가 원인이라는 것은 시각과 동작으로 추정했다. 시스템 설정 내부는 확인하지 않았다.

## 실제 확인 (2026-10-06 14:03~14:05)

제거 스크립트로 지우고 다시 설치한 뒤, 시스템 설정을 미리 열어 둔 채로 진행했다.

- 입력기를 설치하자 "reopening System Settings opened before the input method was installed"가 남았다(14:04:19). 사용자는 + 목록 문제를 다시 보고하지 않았다.
- 두 모드를 추가하자 14:04:56에 "both KeyHue modes enabled; selected English then Korean"이 남았다. 그 뒤 ⌘Space는 KeyHue 영문·한글을 오갔다(14:05:14~15, 14:05:32~36).
- 같은 실행에서 라우팅이 스스로 꺼진 문제와 5단계 권한 문제는 [ADR 0077](0077-apply-a-new-permission-without-restart.md)에서 고쳤다.
