# 0084. "다시 허용"은 허용된 항목을 지우지 않고, 지운 뒤에는 새 프로세스로 요청한다

상태: Accepted (구현·자동 검증, 처음 상태 설치 실제 확인 남음)

날짜: 2026-10-09

관련: [0021](0021-keep-permissions-across-builds.md), [0077](0077-apply-a-new-permission-without-restart.md), [0051](0051-single-app-distribution-and-managed-input-method.md)

## 배경

사용자가 `scripts/uninstall.sh`로 처음 상태를 만든 뒤 입력기를 설치했다.

1. **입력기 설치 및 사용…**이 입력 모니터링을 설명하고 시스템 요청을 띄웠다. 입력 모니터링 목록에 KeyHue가 생겼다.
2. 설치가 끝나자 KeyHue가 바로 다시 실행됐다. 새 프로세스는 아직 권한이 없어서, 1초 뒤 "켜 둔 기능의 권한이 끊겼다" 창을 띄웠다. 이 창은 업데이트로 서명이 바뀐 경우를 위한 것이다(ADR 0021).
3. **다시 허용**을 누르자 `tccutil reset ListenEvent`가 1번에서 생긴 항목을 지웠다. 이어진 요청은 목록에 KeyHue를 다시 넣지 못했다. 권한 DB에 KeyHue의 ListenEvent 항목이 남지 않았다(2026-10-09 09:11).

- macOS는 권한 답을 프로세스마다 처음 받은 대로 기억한다(ADR 0077). 실행 중에 허용해도 그 프로세스는 계속 "없음"으로 보고, 같은 프로세스의 요청도 항목을 만들지 못한다.
- 그래서 "이 프로세스에 권한이 없다"만으로는 항목이 오래된 것인지 알 수 없다. 방금 허용한 항목일 수도 있다.

## 결정

- **설치 직후의 재실행에서는 묻지 않는다:**
  - 입력기 설치·제거 뒤 다시 실행할 때 `--keyhue-relaunched-after-input-method`를 넘긴다.
  - 이 실행에서는 "권한이 끊겼다" 창을 띄우지 않는다. 방금 설명하고 요청한 권한이다.
  - 허용하면 macOS가 "종료 후 다시 열기"를 안내한다. 허용하지 않았다면 다음 실행에서 지금처럼 알린다.
- **다시 허용 (`PermissionFlow.requestAgain`, 메뉴의 권한 허용…도 같음):**
  1. 이 프로세스에 권한이 있으면 지우지 않고 시스템 설정만 연다.
  2. 새 프로세스(`--keyhue-permission-status <서비스>`)가 권한이 있다고 하면 지우지 않는다. 허용은 됐고 이 프로세스만 모르는 것이므로 KeyHue를 다시 실행해 적용한다.
  3. 둘 다 아니면 이전 항목을 지우고, 새 프로세스(`--keyhue-request-permission <서비스>`)에서 요청해 목록에 다시 넣은 뒤 시스템 설정을 연다.
- 손쉬운 사용도 같은 순서를 따른다. 손쉬운 사용은 실행 중 허용을 바로 보지만, 메뉴의 권한 허용…이 허용된 항목을 지우지 않게 하려면 같은 확인이 필요하다.

## 결과

- 처음 설치하는 사용자에게 "업데이트 뒤 끊겼다" 창이 뜨지 않는다.
- 다시 허용을 눌러도 허용된 항목이 사라지지 않는다. 지운 경우에는 목록에 KeyHue가 다시 나타난다.
- 다시 허용을 누를 때 짧은 작업 프로세스가 한두 번(수십 ms) 더 돈다.

## 검증

- `PermissionFlowTests`: 이 프로세스에 권한이 있으면 지우지 않음, 새 프로세스에만 권한이 있으면 지우지 않고 다시 실행, 둘 다 없으면 확인 → 지우기 → 새 프로세스 요청 → 설정 열기.
- `WorkerCommandTests`: 권한 작업 모드 인자, 재실행 인자에 재실행 표시, 재실행된 앱은 작업 모드가 아님.
- 남음 (실제 확인):
  1. `scripts/uninstall.sh` → `scripts/install.sh` → 입력기 설치 및 사용… → 설명 → 시스템 요청.
  2. 재실행 뒤 "권한이 끊겼다" 창이 뜨지 않고, 로그에 `permission check skipped`가 남는다.
  3. 입력 모니터링에서 KeyHue를 켜면 다시 열기 뒤 두 모드 유지가 동작한다.
  4. 메뉴의 입력 모니터링 권한 허용…을 눌러도 목록에 KeyHue가 남는다.
