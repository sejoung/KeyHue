### Remember each window only in the apps you choose

- If **When Switching Apps** is **Restore Last Input Source** and **When Switching Windows in the Same App** is **Keep As Is**, each app remembers one input source. You can now choose apps that remember each window instead. For example, each terminal tab can keep its own language while a messenger keeps one language across all its chats.
- To turn it on, choose **Remember Each Window in 〈app〉** in the menu bar menu while you use that app. Choose it again to turn it off. Settings › Automation › **Apps That Remember Each Window** lists the apps. It has **Remove** buttons and **Add App…**, and you can also remove apps that are not running there.
- In these apps, a new tab or window starts with your default input source. Coming back from another app restores the front window's input source. Panes split inside one window count as one window.
- Like the window option, this needs Accessibility access. The list only applies with the two settings above. If you change them, the list is kept and applies again when you change them back.
- The manual's [Choosing per app](https://sejoung.github.io/KeyHue/manual.html#remember-each-window) has the details.

### KeyHue input method: Korean syllables breaking apart in ChatGPT

- When editing a message in the ChatGPT app, Korean syllables sometimes broke apart: 가난 became `가나ㄴ`. At those times the app turned the input method off while it received each finished syllable, and the input method then also finished the syllable you were still typing. The input method now keeps that syllable and continues it with your next key. If the app stays closed for 2 seconds, the syllable is finished then.

### Other changes

- Saving a setting now writes only the options that changed.

### 고른 앱만 창마다 기억

- **앱을 바꿀 때**가 **마지막 입력 소스로 복원**이고 **같은 앱에서 창을 바꿀 때**가 **그대로 두기**이면, 앱마다 입력 소스를 하나씩 기억합니다. 이제 창마다 기억할 앱을 따로 고를 수 있습니다. 예를 들어 터미널은 탭마다 다른 언어를 기억하고, 메신저는 채팅방을 바꿔도 같은 언어를 씁니다.
- 켜려면 그 앱을 쓰다가 메뉴바 메뉴에서 **〈앱〉에서 창마다 기억**을 고릅니다. 다시 고르면 꺼집니다. 설정 › 자동 전환 › **창마다 기억하는 앱**에 목록이 있습니다. 앱마다 **제거** 버튼과 **앱 추가…**가 있고, 실행 중이 아닌 앱도 여기서 뺄 수 있습니다.
- 이 앱들에서 새 탭이나 창은 기본 입력 소스로 시작합니다. 다른 앱에 다녀오면 맨 앞 창의 입력 소스로 돌아옵니다. 한 창 안에서 나눈 칸은 한 창으로 봅니다.
- 창 옵션과 마찬가지로 손쉬운 사용 권한이 필요합니다. 목록은 위 두 설정일 때만 적용됩니다. 설정을 바꿔도 목록은 남고, 다시 돌리면 그대로 적용됩니다.
- 자세한 내용은 설명서의 [앱마다 기억 단위 고르기](https://sejoung.github.io/KeyHue/manual-ko.html#remember-each-window)에 있습니다.

### KeyHue 입력기: ChatGPT에서 한글 음절이 끊기던 문제

- ChatGPT 앱에서 메시지를 편집할 때 한글 음절이 끊기는 경우가 있었습니다. 예를 들어 `가난`이 `가나ㄴ`이 됐습니다. 이때 앱은 완성된 음절을 받을 때마다 입력기를 껐고, 입력기는 그때 아직 치고 있던 음절까지 확정했습니다. 이제 입력기는 그 음절을 그대로 두고 다음 키에 이어 붙입니다. 앱이 2초 동안 입력기를 다시 켜지 않으면 그때 확정합니다.
