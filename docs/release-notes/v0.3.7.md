### KeyHue input method: the fix shortcut ran a search in Chrome

- In Chrome, pressing the fix shortcut (⌥↩) in a search box such as Google's fixed the word but also ran the search. Chrome passed the key on to the page as Return. The input method now keeps the shortcut from the page in Chromium browsers (Chrome, Edge, Brave, Vivaldi, Opera, Arc, Whale).

### KeyHue 입력기: Chrome에서 고침 단축키가 검색을 실행하던 문제

- Chrome의 Google 검색창 같은 곳에서 고침 단축키(⌥↩)를 누르면 단어를 고치면서 검색까지 실행됐습니다. Chrome이 그 키를 페이지에 Return으로 넘겼기 때문입니다. 이제 Chromium 계열 브라우저(Chrome, Edge, Brave, Vivaldi, Opera, Arc, Whale)에서는 단축키가 페이지에 가지 않습니다.
