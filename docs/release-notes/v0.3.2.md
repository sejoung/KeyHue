### KeyHue input method: fix for repeated Korean characters in some apps

- Fixed Korean typing with the KeyHue input method sometimes entering a character twice (for example `가나나` instead of `가나`). It happened when the app closed the input session while KeyHue was inserting a character; we saw it in Fork. KeyHue no longer shows a character again once it has been entered. If an app closes the session in the middle of a syllable, the syllable still ends there, as it does with the macOS Korean input method.
- Automatic word fixing was not the cause and works as before.

### KeyHue 입력기: 일부 앱에서 한글이 한 번 더 들어가던 문제 수정

- KeyHue 입력기로 한글을 칠 때 글자가 한 번 더 들어가던 문제를 고쳤습니다(예: `가나` 대신 `가나나`). KeyHue가 글자를 넣는 도중 앱이 입력 세션을 닫으면 생기는 문제였고, Fork에서 발생했습니다. 이제 이미 들어간 글자를 다시 표시하지 않습니다. 앱이 음절 중간에 세션을 닫으면 그 음절은 그 자리에서 끝납니다. macOS 한글 입력기도 같습니다.
- 자동 단어 고침 때문에 생긴 문제는 아니며, 자동 고침은 이전과 같이 동작합니다.
