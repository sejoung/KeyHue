### Word fixing: clearer about terminals

- Automatic word fixing at Space never runs in terminals, so commands and paths are never changed while you type. In a terminal, use the shortcut (⌥↩ by default). Settings › Input Method › Word Fixing and the manual now say so; KeyHue behaved this way in 0.3.0 too.
- Reminder: automatic fixing only fixes Korean typed in English mode (`dkssud` → 안녕). To try it, type `dkssud` and Space in a regular app such as TextEdit while KeyHue – English is selected.

### 단어 고침: 터미널 동작 안내

- Space에서의 자동 고침은 터미널에서는 동작하지 않습니다. 입력하는 동안 명령어나 경로가 바뀌지 않게 하기 위해서입니다. 터미널에서는 단축키(기본 ⌥↩)를 쓰세요. 설정 › 입력기 › 단어 고침의 설명과 설명서에 이 내용을 적었습니다. 0.3.0도 같은 방식으로 동작했습니다.
- 참고: 자동 고침은 영문 모드로 친 한글 단어만 고칩니다(`dkssud` → 안녕). 시험해 보려면 TextEdit 같은 일반 앱에서 KeyHue 실험 – 영문을 고른 채 `dkssud`와 Space를 치세요.
