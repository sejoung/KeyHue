### KeyHue input method: more reliable mode recovery

- Improved input session recovery for cases such as Korean mode appearing selected while Latin letters were entered in KakaoTalk. KeyHue now checks that recovery ends in the intended mode and selects it once more if necessary.
- Recovery now checks the active app's input session and stops further recovery actions when the active app changes.

### Keep KeyHue Korean/English Modes no longer turns itself off after a failed switch

- When a mode selection fails or macOS immediately undoes it, KeyHue now pauses automatic mode switching temporarily while keeping your saved setting on.
- Mode switching can resume on the next switching shortcut, click, or app/window/focus change. Typing alone does not trigger a retry, and repeated source changes do not cause a switching loop.
- If an earlier version unexpectedly turned this option off, enable it once again in **Settings › Input Method › Manage › Keep KeyHue Korean/English Modes**.

### KeyHue 입력기: 입력 모드 복구 개선

- 카카오톡에서 한글 모드가 선택돼 있는데 영문이 입력된다는 보고를 바탕으로 입력 세션 복구를 보완했습니다. 이제 복구가 의도한 모드로 끝났는지 확인하고, 필요하면 그 모드를 한 번 더 선택합니다.
- 현재 사용 중인 앱의 입력 세션만 복구 확인에 사용하며, 앱이 바뀌었는지 확인해 추가 복구 동작을 중단합니다.

### 전환 실패 뒤 ‘KeyHue 한/영 모드 유지’가 저절로 꺼지던 문제

- 모드 선택이 실패하거나 macOS가 전환을 즉시 되돌려도, 이제 사용자가 켜 둔 설정은 유지하고 자동 모드 전환만 일시 중단합니다.
- 다음 전환 단축키·클릭·앱/창/포커스 변경 때 다시 동작할 수 있습니다. 일반 글자 입력만으로 재시도하지 않으며, 입력 소스 변경 알림이 반복돼도 전환을 계속 반복하지 않습니다.
- 이전 버전에서 이 옵션이 예상치 않게 꺼졌다면, **설정 › 입력기 › 관리 › KeyHue 한/영 모드 유지**에서 한 번 다시 켜 주세요.
